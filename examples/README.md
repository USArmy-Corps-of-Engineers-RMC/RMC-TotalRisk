# RMC-TotalRisk Example Projects

This folder showcases example projects that demonstrate the capabilities of **RMC-TotalRisk**. As time permits, additional examples will be added to highlight more advanced features and use cases.

To help you get started, we've included two simple example projects created with **Version 1.0**: one for **dam safety** risk analysis and the other for **levee safety** risk analysis. These examples are intended to demonstrate the basic functionality of the software and provide step-by-step guidance on setting up a straightforward risk analysis.

| Project | Opens with |
|---|---|
| `Simple Dam Example.tra` | RMC-TotalRisk v1.0 (see the [README](../README.md) for the download) |
| `Simple Levee Example.tra` | RMC-TotalRisk v1.0 |

As the v1.1 model library matures, headless code examples (building and running a risk analysis directly against `RMC.TotalRisk.dll`) will be added here alongside the desktop projects.
